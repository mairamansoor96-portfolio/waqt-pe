# Waqt Pe

*Medicine care anyone can follow.* A privacy-first family medicine and emergency kit. Nothing you enter leaves the device.

Read [SPEC.md](SPEC.md) for the design and build spec, and [CLAUDE.md](CLAUDE.md) for working rules.

```sh
npm install
npm run dev              # http://localhost:3000
npm test                 # unit tests
npm run build            # static export to out/
node tests/reload.e2e.mjs  # after build: plan survives reload from the link alone
```
